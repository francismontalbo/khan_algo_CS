# Student privacy and source attribution

## Notes

The delivered app has no student accounts, instructor dashboard, database, analytics code or API credentials. Notes and selections use browser storage where available; downloads are created in the browser. Sharing the app files does not create a central collection of students' notes or synchronize them to GitHub.

Export notes before changing devices, clearing browser data, or moving or replacing the local app folder. Do not commit note exports, personal information or credentials. External video players and publisher links make requests to third-party services when used; their own policies apply.
