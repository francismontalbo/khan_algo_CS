# Workflow Algorithm Research Guide

A browser-based guide to graph algorithms and workflow scheduling, starting with Kahn's topological sort. Read the lessons and step through teaching implementations with their assumptions and sources.

## Start using the guide

1. Open [this GitHub repository](https://github.com/francismontalbo/khan_algo_CS) and choose **Code → Download ZIP**.
2. Extract the downloaded ZIP once. Keep all files and folders together.
3. Open `index.html` from the extracted folder in a modern browser.

No installation, build or server is required. The guide works offline; linked papers and videos need internet access. If you already cloned the repository, open its `index.html` directly.

## Save your work

Notes and selections stay in the current browser's storage where available. Export your notes regularly and before moving the guide or changing browsers or devices. Import the saved file to restore them. Uploading the site to GitHub does not synchronize notes. See [NOTICE.md](NOTICE.md) for privacy and attribution details.

## Publish or maintain

To publish the guide online, follow the [GitHub Pages setup](DEPLOY.md). Asset synchronization commands and validation steps are in [TESTING.md](TESTING.md).

Use the working files at the repository root for current changes. [archive/](archive/) preserves earlier deliveries and maintenance records. [reference/Original_Research_Package.zip](reference/Original_Research_Package.zip) retains the original research package.

## Evidence and reuse

The original literature snapshot is dated 15 October 2026. The additive [thesis research library](Thesis_Research.html) has a separate search update dated 19 October 2026, including clearly labeled 2026 publications and preprints. Automated checks cover finite synthetic cases under the guide's declared models. They do not establish scheduling optimality or research novelty. Recheck the original papers and implementation versions before making novelty or production-performance claims.
