WORKFLOW ALGORITHM RESEARCH GUIDE

1. Clone the repository or download its complete ZIP from GitHub.
2. If downloaded as a ZIP, extract all files and folders.
3. Open index.html from the project folder in a modern browser.

The repository already contains the complete application. You do not need
to extract Workflow_Research_Guide_Local_Use.zip; it preserves an earlier delivery.
Keep the companion HTML files and folders beside index.html.
Do not open the app from inside a ZIP or GitHub's source-code viewer.

Read README.md for the guide, DEPLOY.md for optional GitHub Pages hosting,
and TESTING.md for maintainer checks. Students need no installation or server
for a downloaded copy. External papers and videos require internet access.
Export notes regularly and before changing browsers, origins or devices.
