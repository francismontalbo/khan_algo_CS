WORKFLOW ALGORITHM RESEARCH GUIDE

1. On https://github.com/francismontalbo/khan_algo_CS choose Code > Download ZIP.
2. Extract the downloaded ZIP once. Keep all files and folders together.
3. Open index.html from the extracted folder in a modern browser.

No installation, build or server is required. The guide works offline.
Linked papers and videos need internet access.

Export notes regularly and before moving the guide or changing browsers or
devices. Import the saved file to restore them.

README.md introduces the pages. DEPLOY.md explains optional GitHub Pages
hosting for the repository owner. TESTING.md contains maintainer checks.

Earlier deliveries and records remain in archive/. The original research
package remains in reference/Original_Research_Package.zip. Use the working
files beside this note to run the current guide.
