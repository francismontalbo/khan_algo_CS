# Preserved project history

Use the [current README](../README.md) to open the guide and
[DEPLOY.md](../DEPLOY.md) to set up GitHub Pages.

| Folder | Contents |
| --- | --- |
| `packages/` | The original uploaded local-use delivery, preserved unchanged. |
| `maintenance/` | Earlier release notes, packaging logs and maintenance records. |
| `verification/` | Historical algorithm, browser and static-check reports. |
| `Before_Final_Edition/` | The earlier source-record snapshot used by integrity checks. |

These records retain their original text. Their setup commands and file paths
describe the packages that produced them. They are not required for student setup.

Fresh reports go into the ignored `output/ci/` folder. Reports from GitHub runs
are available as artifacts in [Actions](https://github.com/francismontalbo/khan_algo_CS/actions).
The original research package remains in [reference/](../reference/Original_Research_Package.zip).
